Data Sources & Threat Intelligence

Vulnerability and release data are compiled via web scraping and manual curation, relying exclusively on official and verified sources:

  • PostgreSQL Security Matrix: postgresql.org/support/security/
  • Mitre CVE & NVD (NIST): nvd.nist.gov
  • OpenCVE: app.opencve.io/cve/
  • CISA KEV Catalog (Known Exploited Vulnerabilities): cisa.gov/kev

Detailed release information is available in the official PostgreSQL release notes; for a shorter overview, see Your PostgreSQL Stinks!
